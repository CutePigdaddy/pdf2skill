使用教程

按照以下 5 个步骤，把一本 PDF 教材变成可复用的 AI 技能库。

启动方式
命令行运行 python frontend/server.py，浏览器访问 http://localhost:8501 即打开本界面。
也可用命令行向导完成初始配置：python main.py --setup
1
项目介绍
将 PDF 教材/文档自动转化为结构化知识索引与可复用的技能库（SKILL.md + 分块引用文件）。四阶段流水线：
① MinerU（PDF → Markdown） → ② Chunking（语义分块） → ③ Peeling（TOC 剥离） → ④ Skill Engine（生成技能库）
支持断点续跑：Stage 1–3 的结果保存在 outputs/<书名>/.checkpoint.json，重跑自动跳过已完成阶段。
2
准备 API Key
  • 在「配置」面板的 API Keys 区为每个 Provider 填入 Key（保存在当前服务进程内）；或在项目根目录 .env 中配置后重启服务。
  • MinerU 远程模式需要 MINERU_API_KEY；本地模式需要先在本地启动 MinerU 服务。
3
配置 Provider 与模型
  • 在「阶段配置」中为 Chunking / Peeling / Skill Engine 三个阶段分别选择 Provider。
  • 在「Provider 管理」中维护每个 Provider 的 base_url、API Key 环境变量名和三个阶段模型。
  • 点「获取模型列表」拉取该 Provider 可用模型，下拉选择或手动输入；也可以新增自己的 Provider。
4
上传并运行
  • 在「运行」面板拖拽或点击上传 PDF（≤200MB，自动校验格式/页数/加密），或从 inputs/ 选择已有文件。
  • 选择输入模式（PDF / Markdown）与输出目录（默认 outputs/<文件名>）。
  • 点「开始运行」，实时查看三步进度与日志；可随时停止，checkpoint 保证下次断点续跑。
5
查看输出
  • full.md — Stage 1 解析结果；full_chunks_original/、full_chunks/ — 分块与树结构（chunks_index.json、tree.json）。
  • generated_skills/ — 最终技能库：SKILL.md 主索引 + references/ 分块文件 + 打包的 .zip。
  • 在「输出」面板点击文件即可预览内容。

Provider 配置

为每个阶段选择 Provider；Provider 的地址、密钥与模型全部在下方「Provider 管理」中维护。修改后点击「保存配置」生效。

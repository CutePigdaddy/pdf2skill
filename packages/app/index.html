使用教程

按照以下 5 个步骤，把一本 PDF 教材变成可复用的 AI 技能库。全部流水线在浏览器本地运行，后端只做 LLM / MinerU 代理。

启动方式
① 启动代理后端（持有 API Key）：python frontend/proxy_server.py（端口 8502）
② 启动本界面：npm run dev:app，浏览器访问 http://localhost:5173
流水线（分块 / 树剥离 / 技能生成 / 断点续传 / 文件存储）全部在浏览器内完成，输出保存在 OPFS。
1
项目介绍
将 PDF 教材/文档自动转化为结构化知识索引与可复用的技能库（SKILL.md + 分块引用文件）。四阶段流水线：
① MinerU（PDF → Markdown） → ② Chunking（语义分块） → ③ Peeling（TOC 剥离） → ④ Skill Engine（生成技能库）
支持断点续跑：结果保存在浏览器 OPFS 的 jobs/<任务>/.checkpoint.json，重跑自动跳过已完成阶段。
2
准备 API Key
  • 在「配置」面板的 API Keys 区为每个 Provider 填入 Key（只保存在代理后端进程内，永不进入浏览器）；或在项目根目录 .env 中配置后重启代理。
  • MinerU 远程模式需要 MINERU_API_KEY；本地模式需要先在本地启动 MinerU 服务。
3
配置 Provider 与模型
  • 在「阶段配置」中为 Chunking / Peeling / Skill Engine 三个阶段分别选择 Provider。
  • 在「Provider 管理」中维护每个 Provider 的 base_url、API Key 环境变量名和三个阶段模型；可一键从服务端 settings.yaml 导入。
  • 点「获取模型列表」拉取该 Provider 可用模型（需先把 Provider 同步到服务端）。
4
上传并运行
  • 在「运行」面板拖拽或点击上传 PDF（≤200MB，自动校验格式/加密）或 Markdown 文件。
  • 点「开始运行」，实时查看四阶段进度与日志；可随时停止，checkpoint 保证下次断点续跑（同一文件再次上传即自动续跑）。
5
查看输出与导出
  • full.md — Stage 1 解析结果；full_chunks_original/、full_chunks/ — 分块与树结构（chunks_index.json、tree.json）。
  • generated_skills/ — 最终技能库：SKILL.md 主索引 + references/ 分块文件。
  • 在「输出」面板点击文件预览内容，可一键下载 zip（目录结构与命令行版 outputs/<书名>/ 一致）。
